# Reliability test matrix

The G, R, T and C labels refer to the implemented-rule cases in the
[README](../../README.md). Numerical browser fixtures use the currently
implemented configurable bet unit. Exact deadline boundaries use an
injected server clock. The browser checks use real sockets and focus on
visible behavior and representative timing.

| Requirement | Test and verification level | Expected and observed outcome | Limits |
| --- | --- | --- | --- |
| R5/R6, ordinary and invalid admission | [Server tests](../../tests/test_server.py), [lobby interoperability](../../tests/test_integration.py), original live HTTP smoke and browser `errors` | Valid units and codes reserve seats, invalid units and unknown codes leave room state unchanged, and the third join is rejected. | Single worker and one app instance. |
| R6, admission response loss and refresh | [Browser probe](recovery_probe.py) `admission`, [admission tests](../../tests/test_admission_recovery.py) | After upstream success, retries recovered A and B with the original responses. Both browsers entered hand 1 with pot 15, and a third join returned 409. A request dropped before processing allocated once on retry. | One synthetic room per run. |
| R6, concurrent or conflicting admission and retention | [Admission tests](../../tests/test_admission_recovery.py) | Four concurrent creates and four concurrent joins returned equal results per operation. Conflicting operation, unit, or code yielded 409. Malformed and duplicate keys yielded 422. A flood of 96 rejected requests left two recovery records. | Threaded HTTP clients on the same process. |
| R7, origins and credentials | [Transport boundaries](../../tests/test_transport_boundaries.py), browser `errors`, `restart`, and admission probe | Wrong-origin requests never allocated a seat. A same-origin browser and originless clients were accepted. Invalid sessions stopped retrying and returned to admission only after leaving. No recovery key appeared in the monitored DOM, URLs, snapshots, or browser console. | Credential theft and malicious same-origin scripts are outside the model. |
| C1/C2/C4–C6, card and payout privacy | [Browser smoke](../browser-interface/browser_smoke.py) `showdown`, `tie`, `replacement`, `forfeit`, `both-absent`; [browser checks](browser_checks.py) `usability`, `extended` | Expected dealt cards and board streets were observable by their permitted seats. Showdown cards were cleared on a new hand. Fold and disconnect paths kept unrevealed cards private. Hidden DOM had no opponent labels before reveal. | Fixtures use a known first deck and authorized showdown. |
| Static routing and malformed input | [Transport boundaries](../../tests/test_transport_boundaries.py), [server tests](../../tests/test_server.py), [command validation](../../tests/test_commands.py), browser `stale` and `errors` | Source, metadata, evidence and encoded parent paths returned 404. Malformed commands, JSON or stale revisions were rejected without an unintended mutation or echoing request data. | Representative paths and schemas, bounded local testing. |
| G1–G8, legal play and street changes | [Engine cases](../../tests/test_gameplay.py), live showdown/fold/tie checks, browser `showdown`, `tie`, `betting`, `replacement` | Initial pot 15. Call 5 reached pot 20. A bet/raise/call reached pot 60. Browser showdown paid A 210/B 190, tie settled 200/200, and an early fold paid 195/205. | The browser renders authoritative legality. Engine tests cover more rules. |
| G10/G11/R10, next hand and terminal outcomes | Browser `engine-terminal`, `showdown`, and `extended`; [coordinator tests](../../tests/test_coordinator.py) | Two Ready actions advanced the hand once. In mixed-browser replay of five hands the dealer rotated four times, the pot restarted at 15, and both views conserved 400 chips. Terminal controls remained disabled. | First deck is deterministic. Later hands fold rather than re-test every betting branch. |
| R4/R8, engine revisions, stale events and replay | [Node client tests](../../tests/browser/client.test.mjs), [coordinator tests](../../tests/test_coordinator.py), browser `replay`, `stale`, `missing-snapshot`, `pending-refresh` | Stale revisions and old socket callbacks were ignored or rejected. An accepted command with a missing snapshot synchronized from the new connection. Pending refresh or lost acknowledgment retried the same action bytes without a second mutation. | Socket interception changes delivery for the fixture only. |
| R4, repeated same-revision snapshots while pending | [Watchdog probe](recovery_probe.py) and [Node client tests](../../tests/browser/client.test.mjs) | Repeated real snapshots no longer postponed the recovery deadline. Exact replay caused one accepted call and pot 20. The injected monotonic test checked early callbacks and cancellation. | Real elapsed time includes scheduling and socket reconnect. |
| T1/T2, automatic actions | [Deadline tests](../../tests/test_deadlines.py), live timeout-fold and timeout-check, browser `timeout` | Server folded once or checked once as appropriate. Browser emitted no automatic poker mutation. | The browser timeout uses a shortened server fixture. |
| T3–T8, pause/grace/resume and terminal deadlines | [Deadline tests](../../tests/test_deadlines.py), live reconnect/forfeit/both-absent, browser `recovery`, `forfeit`, `both-absent`, `network` | Authoritative loss paused the clock. Timely reconnect restored saved time, and late reconnect could observe the terminal result without reopening play. Independent disconnect deadlines and exact boundaries passed under a manual clock. Local offline hid timing and actions. | Browser verifies visible behavior and avoids exact millisecond boundary assertions. |
| Refresh, replacement, restart and resource cleanup | Browser `replacement`, `recovery`, `restart`, `initial-socket`, `pending-refresh`, `extended`; Node socket authority and heartbeat tests; [slow-writer tests](../../tests/test_coordinator.py) | A duplicated tab displaced the old seat, replacement did not automatically recur, reload reused the same admission, restart invalidated both seats, and one delayed socket write did not block the other. Controlled heartbeat tests counted one timer and ignored stale work. | Short bounded cleanup tests. Actual cache restoration and long-duration memory profiling were outside this run. |
| Keyboard, focus, announcements and card names | Browser `usability`, [accessibility output](usability-results.txt), [desktop screenshot](screenshots/desktop-table.png) | Tab and Shift+Tab found controls. Enter and Space completed a hand and Ready. Visible focus, ARIA card names, and meaningful live messages were present. Undealt spaces and clock ticks were excluded from announcements. | DOM/accessibility snapshots and computed styles. No assistive-technology interaction was performed. |
| Responsive reflow, touch and zoom | Browser `usability`, [touch screenshot](screenshots/touch-table.png) | Six viewport sizes did not overflow horizontally. Root text at 200% reflowed. Touch Check was 156×44 px and a double tap sent one command. | Chromium emulation and root font scaling. Physical devices and native browser zoom were outside this run. |
